## 운영에서 추가 확인할 사항

공개 사이트맵에 `/delivery/qa-삭제-e2e-검증-랜딩`이 포함되어 있으며 실제 H1도 `QA 삭제 E2E 검증 랜딩`이었다. 테스트성 콘텐츠의 공개 상태는 운영 CMS에서 확인해야 한다. 기존 색인 보존 제약과 운영 데이터 보호를 위해 이번 코드 수정에서 해당 레코드를 삭제·보관·noindex 처리하지 않았다.

`NEXT_PUBLIC_SITE_URL`와 `NEXT_PUBLIC_ROBOTS_INDEX`는 빌드 시점 값이므로 운영은 정식 도메인과 true, Preview/branch는 false를 유지한다. 코드 푸시와 운영 배포 성공, sitemap 제출 성공, 검색 반영 성공을 각각 따로 확인한다.

Google sitemap 제출은 대준 Chrome의 해당 사이트 Search Console에서 실제 제출 성공이 확인되어야 완료다. 브라우저 접근 제한 상태에서 완료했다고 표시하거나 다른 프로필/색인 API로 우회하지 않는다.

순위 회복 여부는 재수집 이후 해당 속성의 완료된 28일·90일 검색어/페이지 성과와 실제 문의 변화로 판단한다. 현재 성과 자료가 없으므로 보호군은 기존 공개 URL 전체로 취급하고 광범위한 제목 재작성·삭제·통합은 진행하지 않았다.
